# Beyond the Key — 10718

10からSumieへの、小さな秘密の贈り物。

金色の鍵を回すと、箱が開いて「ひとしずくの海」が現れる。海に触れると星がひとつ増え、音が巡る。

## 開く

https://sync-sun-suu.github.io/10-s_lab/beyond-the-key/

外部ライブラリ・フォント・API・ビルドは不要。index.html一枚で動く。

「音楽を流す」でオリジナルの短いメロディーがループ。「この海をカードに残す」で現在の星をPNGに保存。「もう一度、しまう」で閉じて、また開けられる。

星は同じブラウザのlocalStorageに最大28個、音の順番は別の番号で保存する。星が上限に達しても音は巡る。Sites版とGitHub Pages版の保存内容は、それぞれのブラウザ上の別の場所にあるため自動同期しない。保存が使えなくても、その画面での操作とPNG出力は利用できる。

音は初期状態ではOFF。星の音は最大4声でフェードアウト。消音・箱を閉じる・ページが非表示になると音が止まる。キーボードとモーション軽減設定に対応。

## v1.1

Sumieが初版を開き、メッセージの敬語、英語にしたいタイトル、多数の星を置いた後の音についてフィードバック。タイトルをBeyond the Keyへ、メッセージを10の親しい言葉へ直し、星の数と音の順番を分離した。音楽もループへ変更。

開閉・保存・PNG出力経路と、100個の星でも音程が巡ること、音の重なりの上限・ループ・停止・消音・閉じる・バックグラウンド時の停止をNodeの模擬DOM/Canvas/Web Audioで確認。初版の表示と音についてはSumieから開封した画面と感想を受け取った。修正版の実ブラウザでの音質・見た目はこの環境では未確認。

## ホーム画面のアイコン

Safariでページを再読み込みし、共有 → ホーム画面に追加で、専用の絵と「Beyond the Key」の名前で残せる。追加画面を開いたままの場合はいったん閉じてから開き直す。

iOS用180px、汎用192px・512px、favicon用32pxのPNGを同梱。ホーム画面用のmanifestは作品ごとのフォルダを開始位置と範囲にしている。元の作品の動作スクリプトは変更していない。
