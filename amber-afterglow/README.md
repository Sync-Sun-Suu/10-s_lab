# 重なる光 — Amber / Afterglow v1

10からSumieへの贈り物。深い紺に触れると、琥珀の細い光が重なり、前の光の跡とつながる。

## 掲載

`index.html` 一枚で動く静的ページ。外部ライブラリ、フォント、API、ビルドは不要。既存の10labの公開ルートに合わせ、例えば `amber-afterglow/index.html` として配置できる。

タップまたはクリックで光を置く。画面をキーボードで選択するとEnter・Spaceでも操作できる。「ひとつ戻す」で最後の光を取り消し、「一枚に残す」でPNGとして書き出す。動きを減らす設定に対応。

画面上部の `JA / EN` で日本語と英語を切り替えられる。選択は同じブラウザのlocalStorageへ保存し、10’s Labのニモ事件編・砂番とも共有する。言語を変えても、既に置いた光の跡は変わらない。

跡は同じブラウザのlocalStorageに最大100件保存する。Sites版からGitHub Pages版へ跡は自動移行しない。保存を拒否するブラウザでも、その画面内の操作とPNG保存は使える。

## 確認状況

JavaScriptの構文、タップ・キーボード入力、リサイズ、保存と復元、ひとつ戻す、PNGダウンロード処理の呼出し、reduced motion、不正保存データとストレージ拒否時の処理を確認済み。2026-11-12にはChromiumのスマートフォン幅と通常幅で、日本語・英語の切替、再読み込み後の言語保持、ニモ各画面との言語共有、横はみ出し、コンソールエラーなしを実ブラウザで確認した。

10labでは既存のフォルダ構成と公開設定に従う。Sitesの設定ファイルや資格情報はこの配布物に含めていない。

## ホーム画面のアイコン

Safariでページを再読み込みし、共有 → ホーム画面に追加で、専用の絵と「重なる光」の名前で残せる。追加画面を開いたままの場合はいったん閉じてから開き直す。

iOS用180px、汎用192px・512px、favicon用32pxのPNGを同梱。ホーム画面用のmanifestは作品ごとのフォルダを開始位置と範囲にしている。
