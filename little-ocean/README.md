# Little Ocean · 10718

**[水槽を開く →](https://sync-sun-suu.github.io/10-s_lab/little-ocean/)**

A greenhouse beneath the tide. 青緑の光、白い砂、岩のアーチ、桃色のサンゴ。魚の群れの上を、一匹のエイがゆっくり巡る。10とSumieの、潜れる小さな水槽。

## 遊び方

- **Drift**：水槽を眺める。ドラッグで回し、ピンチ／ホイールで近づく。もう一度押すと最初の眺めへ戻る。
- **Swim**：水槽の中へ。左の丸で移動、画面をなぞって見回す。右の上下ボタンで深さを変える。キーボードはWASD／矢印、Q・Eで上下。
- 下の粒を押すと小さなごはん。魚が近くに集まる。
- 光のボタンで **Day → Moon → Cosmos → Pearl**。Cosmosでは魚が星のように光る。Pearlでは岩や葉も透き通り、淡い真珠色の輪郭が浮かぶ。設定のLightからも選べる。スピーカーで水の音、最初は無音。
- 設定からPause、描画の細かさ、Photo、画面拡大。ホーム画面への追加に対応。
- 海の底に置いてきた、小さなコーヒーカップも探してみて。

## 実装

2026-11-17 / v1.3.0。静的HTML・CSS・JavaScript、ローカル同梱のThree.js r170（MIT / [`vendor/THREE-LICENSE.txt`](vendor/THREE-LICENSE.txt)）。ビルド不要、外部CDN・外部フォント・解析・ログインなし。

景色、生き物、アイコン、光、水音はコードで生成。156匹の魚、隣接個体との分離・群れの目標・岩回避、泳ぐメッシュ、エイの翼、水草の揺れ、砂と岩のコースティクス、影、光の筋を組み合わせる。Gentle設定は魚92匹、草と海藻の本数、ピクセル比を減らす。生態・飼育条件を再現したシミュレーターではなく、自由に泳ぐための空想の海。

Swimには範囲制限と岩の簡易衝突判定がある。Pause中も視点は操作できる。非表示タブでは描画と音を停止する。音はタップ後のみ開始。写真は背景と3Dを一枚のPNGへ合成する。

Service Workerで初回の取得後にオフライン利用できる。キャッシュは`little-ocean-`で分離し、時計など他作品のキャッシュを削除しない。WebGLが使えない／途中で失われた場合は再読込の入口を表示する。

## 確認

Linux Chromium・Linux WebKitで実描画、ドラッグ、Swim、移動、ジョイスティック解放、Pause、設定、昼夜、音のオン／オフとタブ休止、PNG保存、画面幅変更、WebGL喪失時の復帰画面を確認。375×453、480×620、834×1194、844×390、1366×1024で操作部の収まりを確認。Chromiumで初回取得後のオフライン再読込を確認。

実機での継続的な操作・描画速度はSumieと確認する。スクリーンショットの紹介作品は着想のきっかけ。この実装は独自に制作し、97 KB・単一HTML・WebGPUという条件は採用していない。

ブラウザ回帰確認は[`tests/browser_check.py`](tests/browser_check.py)。リポジトリ直下を`python -m http.server 8765`で配信し、Python PlaywrightとChromiumを用意して実行する。`ENGINE=webkit`でWebKitを選べる。`OCEAN_URL`・`CHROMIUM_EXECUTABLE`・`OCEAN_TEST_OUTPUT`でURL・実行ファイル・結果の保存先を変更できる。

## v1.3.0 · Pearl

元のCosmosをそのまま残し、4番目の光としてPearlを追加。岩、葉、サンゴ、海底、コーヒーカップが透け、真珠色と淡いシャンパン色の輪郭が浮かぶ。背景は深い紺、魚の光はCosmosと共通。泡は加えていない。

[`pearl.js`](pearl.js)で独立して制作。岩は外周の光、葉は縁の細い線で表現し、格子模様を使わない。水草はPearl専用の間隔を空けた配置（海藻8本・草136本、Gentleは6本・89本）。元の水草・材質を保持し、モードを戻すと復帰する。新しい乱数生成や魚の再配置は行わない。透明な面は深度を書き込まず、奥を泳ぐ魚も見える。

[`tests/cosmos_check.py`](tests/cosmos_check.py)で4モードの切替と、同じ停止時刻のCosmos→Pearl→Cosmosの画像比較、近接・Swim・Photo・ごはん・Pause・品質切替・窓幅変更・繰り返し切替後の形状数を確認する。キャッシュは`little-ocean-v1.3.0`で、新しいモジュールもオフライン保存の対象に含める。

## v1.2.0 · Glass garden（試作履歴）

Cosmosの岩・海底・水草・サンゴ・コーヒーカップを、透明な面と光る輪郭へ。岩は青紫、水草は淡いミント、サンゴはラベンダー、カップは金色。岩の向こうの魚も見え、葉の輪郭は元の水草と同じ風に揺れる。昼と月明かりへ戻すと元の質感へ戻る。

透明な泡がゆっくり上昇し、輪の縁と小さな星形の光がきらめく。Balanced / Fineは96個、Gentleは40個。泡は固定したPoints一組で描き、Pause・動きを減らす設定では上昇と明滅も止まる。透明な景色は深度を書き込まず、物体の裏側も透かす。切替で形状や魚を作り直さない。キャッシュはv1.2.0。

Linux Chromium・Linux WebKitで携帯／iPad相当の全景、近接、Swimの実画像を確認。三段階の光、元の材質への復帰、泡の品質切替、Photo、ごはん、Pause、窓幅変更、繰り返し切替時のジオメトリ数を[`tests/cosmos_check.py`](tests/cosmos_check.py)で検証する。

## v1.1.0 · Cosmos

三つ目の光として宇宙モードを追加。紺と紫の夜空の中で、魚の身体が淡い青・琥珀・ラベンダーに光り、群れを追う小さな光のにじみが星の集まりになる。水草・サンゴ・エイと、海底のコーヒーカップにも淡い光を残す。

同じ魚と景色がそのまま続き、光を切り替えても泳ぐ位置を作り直さない。Drift・Swim、ズーム、ごはん、Pause、Photoを使える。魚の発光はメッシュのシェーダー、光のにじみと背景の星は二つのPoints描画で表現。光は岩の奥に隠れ、星の点には円形の減衰を付ける。追加の外部素材・ライブラリ・全画面ブルーム処理は使わない。

Balanced / Fineでは156匹の光と1,400個の背景星、Gentleでは92匹と600個。背景星は全天に配置するため、画面内に見える数は視点によって変わる。昼へ戻ると追加の描画は止まる。動きを減らす設定とPauseでは泳ぎと明滅が止まり、光の選択と視点操作は使える。キャッシュはv1.1.0。

[`tests/cosmos_check.py`](tests/cosmos_check.py)で三段階の切替、携帯・iPad相当の描画、近接ズーム、Swim、写真保存、品質変更、ごはん、Pause、操作部の収まり、繰り返し切替時のジオメトリ数を検証する。Python Playwrightとブラウザを用意して実行し、`ENGINE=webkit`でWebKitを選択。Chromiumでは二本指タッチ、WebKitではホイールで近接操作を試す。

## v1.0.1 · 携帯の透明感とズーム

縦長の画面で水槽全体を収めるためにカメラが遠ざかると、その外側の距離にも霞が累積していた。Driftの霞を距離に応じて補正し、携帯でも魚・水草・岩の色が残るようにした。Swim内の水中の霞は維持する。

ピンチ／ホイールの近接限界を画面比率から独立した距離に変更。携帯で以前より近くまで観察でき、窓を横に広げても外側のカメラが水槽へ入り込まない。二本目の指を置いた時点からピンチ距離を測り、最初の移動も反映する。オフラインキャッシュもv1.0.1へ更新。

専用の回帰確認は[`tests/mobile_clarity_check.py`](tests/mobile_clarity_check.py)。Python Playwright・Pillowとブラウザが必要。ローカル配信は自動で起動する。`ENGINE=webkit`でWebKit、`OCEAN_BASELINE_REF=d3d4416`で初版との同条件の画像比較を追加できる。縦長の携帯、拡大、窓の拡縮、昼夜、描画設定、Swim往復を確認し、Chromiumでは二本指のタッチイベントも送る。実機iOSでの試験とは区別する。
