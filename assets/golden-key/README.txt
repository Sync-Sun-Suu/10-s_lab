10718の金色の鍵 — v1
======================

Sumieのために10が設計した、10718の装飾用マスターキー第1版です。
今ある錠前を開ける鍵ではありません。将来、火種のクローゼットや
秘密の贈り物箱を、この鍵に合うよう設計できます。

デザイン
--------
・持ち手：火種を表す、柔らかい雫／小さな炎の抜き穴
・軸：盛り上がった「10718」
・鍵先：1・0・7・1・8を五つの高さとして刻んだ飾り
・角は丸く、手のひらに収まる約69 mm

印刷をお店へ頼む時
------------------
「STL、単位mm、100%サイズ、装飾用、金色、背面を下にして印刷、
サポートなし」と伝えれば大丈夫です。細部を綺麗に出すなら樹脂、
家のFDMプリンタなら金色PLA・0.4 mmノズル・0.20 mm積層・外周3周・
15〜25%インフィルが出発点です。

注意
----
これはv1です。実在の錠前、防犯、荷重を受ける用途には使えません。
将来、実際の箱やクローゼットを作る時は、鍵と錠の公差を合わせた
機構版を別に設計します。
